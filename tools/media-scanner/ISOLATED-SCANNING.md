# Isolated local scan
Stage only authorized media under /srv/xero-media-scan. Files and directories must be readable/traversable by the dynamic service user; use a dedicated staging directory, not existing server application folders. Manifest URLs must be absolute local paths there. Install scanner.py under /opt/xero-media-scan and the accompanying unit under /etc/systemd/system. Stage episodes.json in the service state directory with permissions readable by its dynamic user. Run systemctl daemon-reload and start xero-media-scan.service manually. Check exit status before using results.json; failed or interrupted scans may leave incomplete output. Import results through Media Intelligence and review all timestamps. No remote downloading or automatic approval is enabled. Do not schedule until runtime and real-media accuracy have been checked. The service is network-isolated and resource-limited, but is not a complete sandbox for malicious media.
