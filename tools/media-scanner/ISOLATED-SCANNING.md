# Isolated local scan
Install the workers under /opt/xero-media-scan and units under /etc/systemd/system. Keep staging separate from other applications. Only authorized direct media from the configured approved host may be downloaded.

Configure root-only /etc/xero-media-stage.env with XERO_MEDIA_ENDPOINT and XERO_SCANNER_TOKEN. Run run-stage.sh auto with those environment variables or start xero-media-stage.service manually. Staging is limited to three episodes and 2 GiB per run, 100 GiB cumulative direct files and 10 GiB free reserve. Review accumulated.json in /var/lib/xero-media-staging. Publish it with submit-scan.py --reviewed; this writes /var/lib/xero-media-input/episodes.json. Start xero-media-scan.service and check successful exit before importing /var/lib/xero-media-scan/results.json into Media Intelligence. Review all timestamps before approval.

The optional staging timer is installed disabled until authenticated real-media testing succeeds. No automatic approval or deletion is enabled. Scanner output is replaced atomically on successful JSON validation; old output may remain after a failed run. The scanner is network-isolated and resource-limited, not a complete malicious-media sandbox.
